# T4 — Storage protection

**Goal:** Change one export file, re-sync to S3, list versions; get object via presigned URL.  
**Expected:** Prior version listed; presigned URL works, public URL denied.  
**Date:** 2026-11-26

## Commands

```bash
BUCKET=pubg-oracle-cse363-992382742407

# Upload v1
echo "version 1 content" > /tmp/test_v1.txt
aws s3 cp /tmp/test_v1.txt s3://$BUCKET/t4test/testfile.txt

# Upload v2 (modified)
echo "version 2 content modified" > /tmp/test_v2.txt
aws s3 cp /tmp/test_v2.txt s3://$BUCKET/t4test/testfile.txt

# List versions
aws s3api list-object-versions --bucket $BUCKET --prefix t4test/testfile.txt

# Presigned URL (short expiry)
aws s3 presign s3://$BUCKET/t4test/testfile.txt --expires-in 300

# Public URL (should be denied)
curl -s https://$BUCKET.s3.us-east-1.amazonaws.com/t4test/testfile.txt
```

- Presigned URL (short expiry) returns the object successfully.
