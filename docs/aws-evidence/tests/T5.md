# T5 — Recovery

**Goal:** Restore EBS snapshot to a new volume, mount, read a record.  
**Expected:** Sample record readable from restored volume.  
**Date:** 2026-11-26

## Commands

```bash
# Create snapshot of the data volume
aws ec2 create-snapshot --volume-id vol-07379544f7a798551 \
  --description "pubg-oracle T5 recovery test"
# => snap-00a7adc7934d03168
aws ec2 wait snapshot-completed --snapshot-ids snap-00a7adc7934d03168

# Create new volume from snapshot
aws ec2 create-volume --snapshot-id snap-00a7adc7934d03168 \
  --volume-type gp3 --availability-zone us-east-1a
# => vol-0c9c9821c92d55f8d

# Attach to instance
aws ec2 attach-volume --volume-id vol-0c9c9821c92d55f8d \
  --instance-id i-0a52583fd325b9e87 --device /dev/sdg

# SSH in and mount
sudo mkdir -p /mnt/recovery-test
sudo mount /dev/nvme2n1 /mnt/recovery-test
ls /mnt/recovery-test/models/ | head -5
ls /mnt/recovery-test/data/
cat /mnt/recovery-test/data/.persistence_marker
sudo umount /mnt/recovery-test
```
