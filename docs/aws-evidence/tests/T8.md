# T8 — Operational failure

**Goal:** `docker compose stop api`, watch bot error, `docker compose start api`, re-test.  
**Expected:** Team diagnoses via logs, system recovers.  
**Date:** 2026-11-26

## Commands

```bash
# Stop api
docker compose -f docker-compose.yml -f compose.aws.yaml stop api

# Observe bot/scheduler status (bot still restarting due to placeholder creds)
docker compose -f docker-compose.yml -f compose.aws.yaml ps

# Restart api
docker compose -f docker-compose.yml -f compose.aws.yaml start api

# Re-test
curl -s http://localhost:8000/healthz
docker compose -f docker-compose.yml -f compose.aws.yaml ps
```

## Output (redacted)


**After api restart:**

```
pubg-oracle-api-1   Up (health: starting) -> healthy
```

## Result: PASS

- API stopped; scheduler remained running (its own loop is independent).
- After `start api`, `/healthz` returned `{"status":"ok"}` and the api container recovered to healthy.
- System recovered without manual intervention (restart policy + healthcheck).
